# Welcome to Pacific Coding Community 🌴💻

We are a collaborative community focusing on open-source software and data science across the Pacific region.

## 🚀 Projects
- **Digital Earth Pacific:** Earth observation & multi-temporal change detection projects.
- **Python & Data Science:** Open-source notebooks and learning materials.
